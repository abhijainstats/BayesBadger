# BayesBadger
R package for a Bayesian BetA Double GEneralized Regression with mean modeled using individual-level covariates and precision modeled through cluster-level covariates. The model also allows for spatial smoothing through a graph Laplacian prior. 

Run the following code to install and begin using the package:
install.packages("remotes")
remotes::install_github("abhijainstats/BayesBadger")
library(BayesBadger)
